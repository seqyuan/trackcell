# Test fixtures

Three minimal but structurally faithful vendor bundles, plus a small SCT
golden set. They exist so that trackcell code can be **run and verified without
owning real data** — by a human sketching a pipeline, or by an agent that just
read a docstring and wants to know whether its snippet actually works.

The vendor bundles are generated by `scripts/make_fixtures.py` from a fixed
seed, so regeneration reproduces identical **content**. Not identical **bytes**
— pyarrow, HDF5 and libpng all change their encoding between versions, and
pinning them to keep a hash stable would make these fixtures an assertion about
those libraries. Verified against the current readers by
`tests/test_fixture_contract.py`.

```bash
python scripts/make_fixtures.py --check   # rebuild + read back + assert
python -m pytest tests/test_fixture_contract.py -q
```

Total size ≈ 380 KB.

## `hd_cellseg_tiny` — Visium HD cell segmentation

SpaceRanger 4.0 `segmented_outputs` layout.

| | |
|---|---|
| Cells | 36, on a 6×6 grid, 100 px pitch, origin (1000, 1000) |
| Genes | 40 |
| Coordinates | **full-resolution image pixels** — `obsm['spatial']` |
| `scalefactors` | `microns_per_pixel: 0.3`, `tissue_hires_scalef: 0.5` |
| Cell types | 4 spatially coherent blocks in `obs['classification']`: Tumor (×2), Stroma, Immune |
| Polygons | irregular octagons in `uns['spatial'][sample]['geometries']` + WKT in `obs['geometry']` |
| Images | synthetic pink tissue, 500×500 hires / 125×125 lowres |

```python
import trackcell as tcl
adata = tcl.io.read_hd_cellseg("tests/data/hd_cellseg_tiny")
```

**Exercises:** `read_hd_cellseg`, `sync_geometries_after_subset`,
`resolve_microns_per_unit`, `cells_in_radius`, `hd_labeldist`, `pl.spatial_cell`,
`pl.add_scale_bar`, `pl.mark_circle`, `pl.mark_region`.

Because coordinates are **pixels** with `microns_per_pixel = 0.3`, this is the
fixture to use when testing unit conversion: 100 px pitch = 30 µm pitch, so a
`cells_in_radius(radius=30, radius_unit='um')` query must return neighbours and
`radius=30, radius_unit='data'` must not.

## `hd_bin_tiny` — Visium HD 16 µm bins

SpaceRanger 4.0 `binned_outputs/square_016um` layout.

| | |
|---|---|
| Bins | 100, on a 10×10 grid, 32 px pitch |
| Genes | 40 |
| Barcodes | 10x-style 16-mers with `-1` suffix |
| `tissue_positions.parquet` | `barcode`, `in_tissue`, `array_row`, `array_col`, `pxl_row_in_fullres`, `pxl_col_in_fullres` |

```python
bins = tcl.io.read_hd_bin("tests/data/hd_bin_tiny", binsize=16)
```

**Exercises:** `read_hd_bin`, `pl.spatial_squarebin`, `pl.spatial_bin`.

## `xenium_tiny` — Xenium with two tissue sections

Xenium `outs` layout. **Coordinates are micrometres**, matching real Xenium output.

| | |
|---|---|
| Cells | 40, in two sections 3 000 µm apart |
| Genes | 40 |
| Section 0 | 20 cells, Tumor/Stroma mix at (1000, 1000) |
| Section 1 | 20 cells, all Immune at (1000, 4000) |
| `pixel_size` | 0.2125 µm/px in `experiment.xenium` |
| Boundaries | cell (r≈28 µm) and nucleus (r≈12 µm) polygons, 10 vertices each |
| Composition | deliberately different per section, so per-slice summaries differ |

```python
xad = tcl.io.read_xenium_cellseg("tests/data/xenium_tiny", verbose=False)
```

**Exercises:** `read_xenium_cellseg`, `spatial_slice_cluster` (must find exactly
**2** sections at `eps=80`), `split_by_slice`, `slice_cluster_summary`,
`write_slice_annotation`, `pl.spatial_cell`.

> No cell-type labels are injected: `read_xenium_cellseg` only copies the
> documented `obs` columns. Compute clusters with scanpy if a test needs them.

## `sct_golden` — fast R parity for SCTransform

A 40-gene × 120-cell deterministic integer matrix plus the output of R
`sctransform::vst(vst.flavor='v2')`. `n_cells` / `n_genes` cover the whole
matrix, so R subsampling does not participate and the Python implementation can
run the same matrix in full.

| File | R output |
|---|---|
| `umi.csv` | input, genes × cells |
| `model_pars.csv` | step-1 `theta`, `(Intercept)`, `log_umi` |
| `model_pars_fit.csv` | regularised parameters |
| `genes_log_gmean.csv` | log10 geometric means |
| `gene_attr.csv` | detection rate, mean/variance, residual variance |
| `residuals.csv` | Pearson residuals (40 × 120) |
| `meta.json` | R/sctransform versions and settings |

`tests/test_sct_r_golden_small.py` runs the Python `vst` on these counts and
asserts R parity in ~2 s, so it runs on every PR instead of being skipped with
the external benchmark suite. Regenerate with:

```bash
Rscript tests/data/sct_golden/export.R tests/data/sct_golden
```

## Conventions

- **Do not hand-edit these files.** Change `scripts/make_fixtures.py`, rebuild,
  and commit both. `test_fixture_builders_are_deterministic` compares content
  (parquet as dataframes, PNG as pixels, HDF5 as datasets), so a stale committed
  copy fails the suite. The `sct_golden/` directory is the exception: it is
  regenerated by `sct_golden/export.R`, not by `make_fixtures.py`.
- Regenerating with a different pyarrow version rewrites parquet bytes and will
  show a binary diff even when nothing changed. Only re-run the script when the
  builders change.
- Keep the total under ~500 KB. PNG is the dominant cost; keep shading smooth
  rather than per-pixel noisy so it compresses.
